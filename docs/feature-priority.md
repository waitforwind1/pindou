# 拼豆图纸生成工具：功能优先级与 MVP

| 项目 | 内容 |
| --- | --- |
| 文档版本 | v1.1（P02 深化） |
| 日期 | 2026-11-06 |
| 依据 | `docs/requirements.md` v1.1、`docs/acceptance.md` v1.1、`docs/product-design.md` v1.0 |
| 交付周期 | 72 小时 |
| 约束 | 完整 P0 闭环优先；不虚构色号；不引入与规模不匹配的架构 |
| 推荐形态 | 纯前端单页工具，本地处理，Canvas 2D，内置经核验色盘快照 |
| 已确认 | Hama 67 色、32/48/64 预设、PNG 导出、A<128 为空/A>=128 白底 |

## 1. 决策原则

排序不是“功能看起来酷不酷”，而是同时看四件事：

1. **原题强制**：P0 缺一项即不交付，不能拿进阶功能抵扣。
2. **用户闭环价值**：是否直接帮助用户完成“上传→生成→采购/摆放→下载”。
3. **实现与验证成本**：72 小时内是否能做对、测透，而不是只做出演示。
4. **真实性风险**：任何依赖未核验色号、复杂分板规则或跨品牌数据的增强，都不能挤占 P0 验证时间。

## 2. 优先级总览

| 等级 | 定位 | 发布策略 |
| --- | --- | --- |
| P0 | 原题强制闭环与数据真实性 | 必须全部通过；不可降级为“以后再做” |
| P1 | 显著提升实际使用价值、成本可控 | P0 验收通过后再做；MVP 只纳入最低成本项 |
| P2 | 有价值但成本/风险明显更高 | 明确延期，不作为本次交付承诺 |

## 3. P0：必须交付

### P0-01 图片上传与解码

- 支持 PNG；兼容 JPEG、WebP。
- 本地读取、EXIF 方向、常见错误提示、大小/像素上限。
- 不依赖服务端上传。
- 依赖：无。
- 追踪：FR-01、AC-01、AC-02。
- 估算：6-8 小时（含测试夹具）。

### P0-02 像素读取、透明判定与有效格定义

- 读取 RGBA；A<128 为空，A>=128 白底合成。
- 预乘 alpha 缩放，避免边缘彩边。
- 全透明图阻止生成。
- 依赖：P0-01。
- 追踪：FR-02、FR-03、AC-03、AC-04。
- 估算：4-6 小时。

### P0-03 目标尺寸与采样

- 至少 32×32、48×48、64×64 预设，默认 64×64。
- contain + 最近邻，输出精确目标网格。
- 尺寸、比例和有效豆数可见。
- 依赖：P0-02。
- 追踪：FR-04、AC-05、AC-06。
- 估算：6-8 小时。

### P0-04 真实 Hama 色盘

- 官方 2026 Midi Solid 67 色；色号、英文名、参考色、来源、哈希、采样记录完整。
- 启动时校验，失败禁止匹配。
- UI 与导出图披露“参考色非官方 RGB”。
- 依赖：不依赖界面；必须在编码前冻结数据契约。
- 追踪：FR-05、AC-07 至 AC-09、AC-14。
- 估算：8-12 小时（含人工核对，不能压缩到“抓一张图就用”）。
- 风险：最高。色盘错误会让整个产品失去可信度。

### P0-05 最近实体色匹配

- sRGB→CIELAB，CIE76 最近色；平局按色号升序。
- 每个有效格保存色号；空位不匹配；结果确定。
- 依赖：P0-02、P0-03、P0-04。
- 追踪：FR-06、AC-10 至 AC-12。
- 估算：5-7 小时。

### P0-06 网格图纸与预览

- 全格覆盖、逐格填充、清晰网格线、主网格线。
- 格内色号、行列号、图例、尺寸/豆数/色盘版本。
- 深色/浅色背景下色号均可读。
- 依赖：P0-05。
- 追踪：FR-07、FR-08、AC-15 至 AC-19。
- 估算：10-14 小时。

### P0-07 PNG 独立导出

- 离屏重绘，每格至少 40 px，完整网格、色号、行列号、图例和来源。
- 本地 Blob 下载；失败可重试。
- 断网后独立查看器可读。
- 依赖：P0-06。
- 追踪：FR-10、AC-20 至 AC-23；若实现编辑，另验 AC-P1-09。
- 估算：8-12 小时。

### P0-08 边界处理与验收证据

- 损坏图片、超限、全透明、色盘失败、下载失败。
- 测试夹具、官方来源核对、跨浏览器和断网验收。
- 依赖：贯穿所有 P0。
- 追踪：requirements 第 6 节、acceptance 第 4、6、7 节。
- 估算：8-10 小时。

**P0 合计估算：55-77 小时（含验收与返工）。** 其中核心编码目标在 44 小时前完成，余下时间用于 P0 验收、修复和可读性打磨。区间偏紧，因此必须并行做色盘核对，并把 P1 限制在低成本项；不能先做编辑器再补导出。

## 4. P1：P0 通过后的增强

### 4.0 重点进阶功能比较

| 功能 | 用户价值 | 实现成本 | 技术/产品风险 | 结论 |
| --- | --- | --- | --- | --- |
| 颜色用量统计与材料清单 | 高：直接支撑采购和备豆 | 低：3-5h | 低：需与格子状态派生同步 | P1 第 1，MVP 目标 |
| 实体尺寸/底板估算 | 高：把“格数”变成可制作尺寸 | 低：2-3h | 中：5mm/板规格必须标为假设 | P1 第 2，MVP 目标 |
| 单格编辑 + 撤销/重做 | 高：修正错配、局部设计 | 中：12-18h | 中：统计、图例、导出必须同步 | P1 第 3，非首版底限 |
| 工程保存/恢复 | 中高：长图不丢进度 | 中：5-8h | 中：色盘版本和 schema 兼容 | P1 后段 |
| 照片友好采样 | 中高：普通照片可用 | 中：6-8h | 中高：容易让人误以为自动抠图/风格化 | P1 后段 |
| 大图纸分板打印 | 高：大图能实际制作 | 中：8-12h | 中：板号、全局坐标和边缘板核对 | P1 第 3，本次交付 |
| 色彩匹配策略切换 | 中：风格化/限色需求 | 中高：8-12h | 高：验收口径复杂，易与 P0 最近色混淆 | P2 |

这张表的原则：**先让用户知道“多少颗、多大、怎么下单”，再支持大图分板，最后才做编辑、换品牌和风格化。**

### P1-A 颜色用量统计与材料采购清单

**优先级：P1 第 1 位，建议纳入 MVP。**

- 价值：解决“每色买多少”的高频问题；比单纯看图更接近实际制作。
- 成本：3-5 小时；直接聚合 `PatternDocument`，不需要新数据。
- 风险：低；但必须只统计有效格，且与导出图例一致。
- 依赖：P0-05、P0-06。
- 追踪：FR-09、AC-P1-01。
- 决策：工作量小、价值高，P0 主流程稳定后立即加入。

### P1-B 完整自定义宽高 + 实体尺寸/底板估算

**优先级：P1 第 2 位。**

- 价值：适配真实底板、珠量与打印尺寸，把“64×64 格”翻译成用户能判断的厘米和板数。
- 成本：5-7 小时；需补 8-128 校验、重采样、5 mm 默认中心距、底板公式和免责声明。
- 风险：低到中；大图会影响导出内存，物理尺寸容易被误认为官方精确值。
- 依赖：P0-03、P0-07。
- 追踪：FR-04、FR-14、AC-P1-02、AC-P1-06。
- 决策：P0 已有预设，满足原题；P0 验收通过后优先加入，计入 MVP 目标。

### P1-C 单格编辑

**优先级：P1 第 3 位（编辑与撤销成对）。**

- 价值：用户可修复局部色差、去除噪点、手动做设计调整。
- 成本：8-12 小时；涉及命中测试、重绘、统计和导出同步。
- 风险：中；需要严格保证不能选到非色盘颜色。
- 依赖：P0-06，最好同时具备 P1-A 统计。
- 追踪：FR-11、AC-P1-03、AC-P1-08。
- 决策：若时间只剩 20 小时且 P0 尚未稳定，不做。

### P1-D 撤销/重做

**优先级：P1 第 3 位，必须与 P1-C 成对。**

- 价值：避免误操作破坏图纸。
- 成本：4-6 小时；可用操作栈/状态快照实现，不引入复杂架构。
- 风险：中；状态与统计/导出的同步容易漏。
- 依赖：P1-C。
- 追踪：FR-11、AC-P1-04、AC-P1-08。
- 决策：如果不做单格编辑，本项不做。

### P1-E 工程保存与恢复

**优先级：P1 第 4 位。**

- 价值：刷新/关闭后可继续，长图制作更安心。
- 成本：5-8 小时；JSON 导出优先于 localStorage 自动保存。
- 风险：中；必须绑定色盘版本，避免恢复后色号漂移。
- 依赖：P0-05、P0-06。
- 追踪：FR-12、AC-P1-05。
- 决策：不影响 P0 闭环；排最后。

### P1-F 照片友好采样

**优先级：P1 第 5 位。**

- 价值：普通照片用户不再只能得到随机丢失细节的最近邻结果。
- 成本：6-8 小时；需要照片/像素画模式、区域平均缩放、质量提示和对照测试。
- 风险：中高；用户容易把“区域平均”误解为自动抠图、自动变卡通或保证可制作。
- 依赖：P0-02、P0-03、P0-05。
- 追踪：FR-04、FR-15、AC-P1-07。
- 决策：不属于 MVP 底限；若 P0、P1-A、P1-B 已稳定且仍有至少 8 小时，再做。

**本次 P1 交付范围：** P1-A 材料清单、P1-B 自定义尺寸、P1-C 大图分板。单格编辑、撤销重做、工程文件保存/恢复明确移出本次范围。

| 实时库存/购买链接 | 采购闭环 | 库存/价格/地区变化快，无法在本次可靠承诺 | 正式商品数据接口与商务合作 | — |

## 6. 最合理的 MVP

### 6.1 MVP 定义

MVP 的发布底线是 **P0 全闭环**；本次目标版本是 **P0 全闭环 + P1-A 材料清单 + P1-B 自定义尺寸 + P1-C 大图分板**。单格编辑、撤销重做和工程文件明确不在本次范围。

1. 上传 PNG/JPEG/WebP，显示源图预览。
2. 32/48/64 预设目标尺寸，默认 64×64；contain + 最近邻。
3. 透明像素规则明确，空位不参与匹配。
4. Hama 官方 2026 Midi Solid 67 色，逐格匹配并保存色号。
5. 带逐格网格线、色号、行列号、图例的图纸预览。
6. 颜色用量统计和材料清单（P1-A），页面与导出图例一致。
7. 8-128 自定义宽高（P1-B）和实体尺寸/底板数量估算，明确标注 5 mm 与底板规格假设。
8. 完整 PNG 下载，断网可独立阅读。
9. 色盘来源、派生 RGB 和限制说明可见。
10. 失败路径完整：坏图、全透明、色盘失败、导出失败。

### 6.2 为什么是这套

- 完全覆盖原题四项强制要求，没有用 P1 偷换 P0。
- 颜色统计和尺寸估算直接服务“买多少、做多大”，是最高性价比的“真实制作价值”。
- 不自建账号、后端、库存、AI 抠图或多品牌抽象，避免把 72 小时花在非核心工程上。
- PNG 先于 PDF：原题二选一，PNG 的本地导出和可验证性更稳。

### 6.3 MVP 明确不做

- 单格编辑、撤销/重做、工程恢复作为“P0 通过后的加项”，不承诺进入首版。
- PDF/SVG、多品牌、照片风格化、单格编辑、撤销重做和工程文件全部延期。
- 照片友好采样（P1-F）不进入首版 MVP；P0 只提供安全解码、最近邻和质量告警，不能把“支持上传照片”误写成“已完成照片优化”。
- 不提供“保证实物颜色一致”或“官方认证”表述。

## 7. 72 小时执行计划

以下为时间盒，不是功能承诺；每个检查点未通过就不得盲目叠加 P1。

| 时间 | 工作 | 输出/门禁 |
| --- | --- | --- |
| 0-4h | 冻结 P0、产品设计、官方色盘核对方案、测试夹具设计 | 四份文档确认；色盘来源和 67 色清单无争议 |
| 4-10h | 单页骨架、上传/预览、错误态、目标尺寸 UI | AC-01/02 可手动走通 |
| 10-18h | RGBA 读取、EXIF、alpha 规则、contain/最近邻采样 | AC-03/04/05/06 通过 |
| 18-26h | 色盘数据包、CIELAB 匹配、确定性测试 | AC-07 至 AC-12 通过 |
| 26-36h | 网格渲染、色号排版、行列号、图例、缩放查看 | AC-15 至 AC-19 通过 |
| 36-44h | 离屏 PNG 导出、完整图例、下载失败处理 | AC-20 至 AC-23 通过 |
| 44-52h | 全量夹具、端到端、Chrome/Edge、断网重开、缺陷修复 | P0 验收全绿；保留证据，作为进入 P1 的门禁 |
| 52-56h | P1-A 颜色统计/材料清单 | 统计与导出一致；P0 回归不退化 |
| 56-60h | P1-B 自定义尺寸 + P1-C 分板与材料清单回归 | 不破坏 P0；否则停止加项 |
| 60-66h | 可读性打磨、文案、响应式、性能与内存 | 无 Blocker/Major |
| 66-72h | 冻结代码、演示材料、交付说明、最终回归 | 72h 截止；不临时塞新功能 |

**并行策略**：色盘人工核对/测试夹具可与前端骨架并行，但色盘未冻结前不得进入最终匹配和导出验收。

## 8. 风险与取舍

| 风险 | 概率/影响 | 预防 | 触发后的取舍 |
| --- | --- | --- | --- |
| 官方色卡版本/取样差异 | 中/高 | 固定 PDF 哈希、记录取样方法、67 色逐项核对 | 宁可延期匹配，不伪造颜色 |
| 64×64 导出色号不可读 | 中/高 | 40 px 格宽、12 px 字号、描边、100% 检查 | 调整排版/导出倍率，不删色号 |
| Canvas 大图内存失败 | 中/中 | 尺寸上限、导出前校验、失败提示 | 限制 P1 最大尺寸，不做分板 |
| 最近色结果被质疑 | 中/中 | CIE76 + 自匹配 + 独立参考计算器 | 公开算法与色盘版本，不靠肉眼调色 |
| 透明边缘产生色噪 | 高/中 | 预乘 alpha、50% 阈值、告警 | 保留规则并提示；高级阈值放 P2 |
| 物理尺寸被误当成官方精确值 | 中/高 | 5 mm 默认值、公式、底板规格、免责声明 | 降级为“格数 + 提示”，不承诺厘米/板数 |
| 照片模式被误解为自动抠图/风格化 | 中/高 | 模式说明、前后对照、明确不自动抠图 | 退回 P0 最近邻 + 告警 |
| P1 挤占 P0 测试 | 高/高 | 52h P0 门禁、P0 不绿不进入 P1 | 砍 P1-C/D/E/F；再紧则只保留 P1-A，甚至全部回退 P0 |
| 浏览器字体/导出差异 | 中/中 | 系统字体回退、离屏固定参数、Edge 复测 | 采用更保守字号/固定布局 |
| 色盘数据重分发许可 | 低/中 | 不打包官方 PDF，只存派生必要字段和来源 | 下线不必要的原始色卡文件 |
