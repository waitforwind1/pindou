# ADR-0004：P0 使用 CIELAB ΔE76 进行实体色匹配

- 状态：Accepted（设计基线）
- 日期：2026-11-06
- 关联：`docs/algorithm-design.md` 第 7-8 节；FR-06、AC-10、AC-11

## 背景

每个有效格必须映射到 Hama 67 色中的一个真实色号。匹配算法必须可解释、可复现，并能在 72 小时内验证，而不是凭肉眼或 RGB 近似决定。

## 可选方案

| 方案 | 感知准确性 | 性能 | 可验证性 | 结论 |
| --- | --- | --- | --- | --- |
| RGB 欧氏距离 | 差；RGB 非感知均匀 | 最高 | 容易实现但错误不可接受 | 不采用 |
| CIELAB ΔE76 | 中高；显著优于 RGB | 低；67 色内可接受 | 公式清晰，参考值易测 | **P0 采用** |
| CIEDE2000 | 更高，尤其低色差/色相区域 | 中高；公式复杂 | 需要独立参考实现和大测试矩阵 | P2 策略 |
| 人工/品牌相近映射表 | 可贴合部分经验 | 低 | 不可扩展、难以证明 | 不采用 |

## 决策

P0 固定为：

```text
sRGB -> 线性 RGB -> D65 XYZ -> CIELAB -> ΔE76 最小平方距离
```

- 色盘 Lab 在装载后一次性预计算。
- 每格独立匹配；不合并相近色，不抖动，不限制用色数。
- 距离相同时按官方 code 的固定字典序升序，保证确定性。
- P2 才允许通过显式策略切换 CIEDE2000；不得静默替换 P0。

## 理由

1. RGB 欧氏距离在暗部、蓝色、肤色区域会出现明显不符合感知的选择；不适合“真实实体色”匹配。
2. CIE76 的实现和公式风险显著低于 CIEDE2000，适合 72 小时内完成数值测试与可解释说明。
3. 67 色匹配规模很小，性能不是采用低质量 RGB 距离的理由。
4. 冻结算法、白点、矩阵和平局规则后，AC-11 的确定性可直接验证。
5. CIEDE2000 的收益主要在细微色差，但不同策略会改变材料清单，必须作为版本化策略而不是免费升级。

## 代价与限制

- CIE76 在蓝紫、低色差区域仍不完美；产品文案不能宣称“人眼完全一致”。
- 如果未来切换 CIEDE2000，必须展示前后差异、记录策略版本并重新验收。
- displayRgb 来自官方色卡照片采样，本身不是官方 RGB 标准；算法只能保证“在冻结色盘数据下确定性最近色”，不能保证与实物批次完全一致。
- 匹配结果必须保存色盘索引，不能只留匹配后的 RGB。

## 验证方式

- 至少 12 个已知样本与独立 CIELAB 参考计算器一致。
- 67 色自匹配全部回到自身。
- 相同输入连续 3 次逐格索引一致。
- 构造等距样本验证 code 升序平局，而非数组顺序。
