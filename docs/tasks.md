## 1. 状态与完成口径

- `[ ]` 未开始
- `[~]` 进行中
- `[x]` 已完成，且有可复核的命令或产物证据
- `[!]` 阻塞，或等待用户/外部来源确认

“类型已建立”“函数已写”“测试已规划”都不等于功能完成。P0 功能只有在所属验收项通过后才可整体标记完成。下文把部分 P0 工作拆成纯核心子项，只是为了让验证粒度更清楚，不能据此弱化 P0 验收。

- [x] D65 sRGB→CIELAB：黑、白、RGB 三原色参考值测试。
- [x] CIE76 距离、自匹配、按官方 code 的确定性平局规则。
- [x] `A=127` 为空、`A=128` 有效、白底合成。
- [x] 8×4→64×64 contain：上下各 16 行空位，不拉伸。
- [x] 1:1 最近邻采样与越界读取防护。
- [x] Hama 官方快照：67 个唯一色号/名称、67 个唯一参考 RGB、来源元数据、PDF 哈希和 canonical checksum 复算。

- [x] RGB 欧氏与 CIE76 统一接口：自匹配、平局按官方 code、确定性、空色盘拒绝；深蓝样本实际选出不同 Hama 色号。
- [x] 最近邻/区域平均统一入口：区域平均预乘 alpha、线性光平均、无跨格取样、`A=127/128` 边界。

- [x] 可选 Floyd–Steinberg：默认关闭、显式开启后增加用色数、空位保持、`sourceRgb` 保留、重复结果一致。
